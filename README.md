# eitango — 英単語学習アプリ

スマホ向けの英単語学習アプリ（単一HTML・オフライン動作可）。全2000語・40レベルを収録し、間隔反復（SRS）で復習タイミングを自動管理します。

**公開URL: https://mi-po913.github.io/eitango/**
（スマホのSafari/Chromeで開き、「ホーム画面に追加」でアプリのように使えます）

## 基本の流れ

1. **レベルを選ぶ**（50語ごと＝1レベル、Lv1〜40、複数選択可）
2. **出題の向き・難しさ・語数**などを設定
3. **▶ 学習スタート**でクイズ開始
4. 毎日ひらいて **🔁 今日の復習だけ** をこなすと、忘れかけたころに自動で再出題されて定着します（1日10〜20語が目安）

---

## 「覚えた」になる条件

各単語には内部に **「箱レベル 1〜5」** があります。

- クイズで **正解するたびに箱が1つ上がる**（最大5）
- **不正解だと箱1に戻る**
- **箱が5に達すると「覚えた」** になります

新規の単語からだと、**間隔をあけて4回正解**すると「覚えた」に到達します（箱 1→2→3→4→5）。

> 単語帳モードで **「✓ 覚えた にする」** を押せば、手動で即「覚えた」にもできます（**「↺ 学習中に戻す」** で戻せます）。

⚠️ 「覚えた」は固定ではありません。あとでその単語をクイズで**間違えると箱1に戻り**、また学習対象になります（うろ覚えは戻る設計）。

---

## 復習として再び出てくるタイミング（間隔反復）

正解して箱が上がるほど、**次に出題されるまでの間隔が延びます**。

| 箱が上がる | 次の出題まで |
|---|---|
| 1 → 2 | **翌日（1日後）** |
| 2 → 3 | **3日後** |
| 3 → 4 | **7日後** |
| 4 → 5 | **16日後** |

- **不正解**のとき … 箱1に戻り、**当日中に「今日の復習」**へ戻ります
- **「今日の復習だけ」** … 復習予定日が来た（＝期限切れも含む）単語だけを出題します
- **「学習スタート」** … 今日の復習＋新しい語を出題。どちらも尽きたら、選んだ範囲から自由に練習します

---

## 4つのステータス

単語帳モードで各単語の状態が表示され、フィルタでも絞り込めます。

| 表示 | 意味 |
|---|---|
| **未学習** | まだ一度もクイズに出していない |
| **学習中** | 学習を始めたが、次の復習日はまだ先（覚えている途中） |
| **復習** | 復習予定日が来ている（今日やるとよい） |
| **覚えた** | 箱5に到達（習得済み） |

## 画面・モードの説明

- **▶ 学習スタート**（4択クイズ）
  英単語→意味、または意味→英単語を4択で回答。正解でSRSの箱が上がり、間違えた語は近いうちに再出題されます。
- **🔁 今日の復習だけ**
  復習予定日が来た単語のみを出題。毎日これをやるのが定着の近道です。
- **📖 単語帳モード**
  一覧を検索・タップで意味/例文/発音を確認。ステータス表示と「覚えた⇄学習中」の手動切替、フィルタ（すべて/学習中/復習/覚えた）付き。

## 設定の説明

- **レベル** … 50語ごとに1レベル（Lv1〜40）。複数選択可。
- **出題の向き** … 英語→意味 / 意味→英語 / ミックス。
- **選択肢の難しさ**（誤答の選び方。**選択肢は常に正解と同じ品詞**になります）
  - やさしい … 別レベルの同品詞から（意味が離れ選びやすい）
  - ふつう … 同品詞からランダム
  - むずかしい … 同レベル・同品詞（紛らわしい）
- **1回の語数** … 10 / 20 / 50 / 全部。
- **覚えた語** … 「出題しない」にすると、覚えた語を除いて**まだ覚えていない語だけ**で練習できます。

## 進捗の保存について

- 学習状況・正答率・設定は、**その端末のブラウザ**に自動保存されます（localStorage）。
- アプリを閉じても・端末を再起動しても残ります。
- **別の端末やブラウザには引き継がれません**（同期機能はありません）。ブラウザの「サイトデータ削除」やプライベートモードでは消える/残らない点にご注意ください。

---

## 発音について

- 発音ボタン（🔊）は端末の音声合成（speechSynthesis）を使い、**米国英語の音声を優先**して読み上げます。
- 米国英語の音声が入っていない端末では、Chromeで開く／OSに英語(米国)音声を追加すると、より自然な発音になります。
